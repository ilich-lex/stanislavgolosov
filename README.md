# Персональный сайт Станислава Голосова

Статический сайт юридического кабинета с небольшой защищённой CMS на Supabase. Работает без сборки, npm и собственного backend.

## Запуск

Для полноценной проверки Supabase-запросов запустите папку через локальный HTTP-сервер:

```powershell
python -m http.server 4173
```

## Структура

- `index.html` — содержание, SEO-метаданные и разметка;
- `styles.css` — визуальная система, адаптивность и анимации;
- `script.js` — мобильное меню, появления элементов и индикатор прокрутки;
- `cms-config.js` — публичные параметры подключения к Supabase;
- `cms-public.js` — безопасная загрузка дел и актуальной фотографии с fallback;
- `admin/` — закрытая административная часть без ссылок с публичной страницы;
- `supabase/` — воспроизводимая SQL-схема, RLS policies и миграция исходных дел;
- `assets/images/` — оптимизированные версии фотографии;
- `assets/vendor/` — зафиксированная локальная сборка Supabase JS для админки;
- `assets/icons/` — favicon.

## CMS

Точная последовательность настройки Auth, SQL, Storage и публикации описана в `CMS_SETUP.md`.

## Источники контента

- контакты, услуги, цены, опыт — материалы клиента;
- образование — предоставленные клиентом сведения о дипломе;
- судебная практика — номера и ссылки из файла клиента, без публикации персональных данных и неподтверждённых результатов;
- отзывы — публичная карточка юридического кабинета в 2ГИС, проверено 18 августа 2026 года.

## Перед публикацией

Проверить фактический домен в `canonical`, `og:url` и `og:image`. Сейчас указан ожидаемый адрес `https://golosov.ru/` на основании корпоративного e-mail; при размещении на другом домене эти три значения нужно заменить.
